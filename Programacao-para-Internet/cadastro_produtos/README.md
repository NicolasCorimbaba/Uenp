# Cadastro de Produtos e Clientes

Projeto desenvolvido para a disciplina de **Programação para Internet**, utilizando o framework Django.

O sistema permite realizar o cadastro e gerenciamento de **Produtos** e **Clientes** através do Django Admin, utilizando o Django Jazzmin para a interface administrativa.

## Funcionalidades

- Cadastro de clientes
- Cadastro de produtos
- Cadastro de marcas
- Cadastro de categorias
- Relacionamento entre produtos, marcas e categorias
- Gerenciamento dos dados através do Django Admin
- Interface administrativa personalizada com Django Jazzmin

## Tecnologias utilizadas

- Python
- Django
- SQLite
- Django Jazzmin
